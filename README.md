# Бот репетитора по химии (ОГЭ, 9 класс)

Telegram-бот с мини-приложением для записи на занятия. Работает внутри Telegram на iPhone, Android, Windows, Mac и в веб-версии. Ученику ничего не нужно устанавливать.

- Ученик нажимает «Записаться» в боте, выбирает день и время, а подтверждение приходит ему в чат. В разделе «Мои записи» он может отменить занятие.
- Репетитор получает сообщение о каждой записи и отмене и сам задаёт свободные окна по дням в «Кабинете репетитора» прямо в Telegram.

Ниже инструкция по **бесплатному** запуску: Render (сервер) + Upstash (база данных). Банковская карта не нужна. Займёт 20–30 минут.

> **Учтите:** на бесплатном Render сервер засыпает через 15 минут без посетителей. Первое открытие после перерыва занимает до минуты, дальше всё работает быстро. Данные при этом не теряются: они хранятся в Upstash.

---

## Шаг 1. Создайте бота в Telegram

1. Найдите в Telegram **@BotFather** и нажмите «Старт».
2. Отправьте `/newbot`.
3. Введите название, например `Химия ОГЭ — запись`.
4. Введите username, который должен заканчиваться на `bot`, например `himiya_oge_zapis_bot`.
5. BotFather пришлёт **токен** вида `7123456789:AAH...`. Скопируйте его в заметки. Это пароль от бота, никому его не показывайте.

## Шаг 2. Создайте бесплатную базу в Upstash

1. Откройте **upstash.com** и зарегистрируйтесь (можно через Google или GitHub).
2. Создайте базу **Redis**: кнопка *Create Database*. Название любое, регион выберите ближе к Европе, тариф бесплатный (Free).
3. Откройте созданную базу и найдите блок **REST API**.
4. Скопируйте в заметки два значения:
   - `UPSTASH_REDIS_REST_URL` — адрес вида `https://....upstash.io`
   - `UPSTASH_REDIS_REST_TOKEN` — длинный ключ

## Шаг 3. Загрузите проект на GitHub

Render берёт код с GitHub, поэтому сначала проект нужно загрузить туда.

1. Зарегистрируйтесь на **github.com**.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Название, например, `chem-tutor-bot`. Выберите **Private** и нажмите **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**.
5. Распакуйте архив, откройте папку `chem-tutor` и **перетащите всё её содержимое** (файлы `server.js`, `bot.js`, `store.js`, `render.yaml`, `package.json` и папку `public`) в окно браузера.
6. Внизу нажмите **Commit changes**.

Проверьте, что в репозитории видна папка `public` и файл `render.yaml` лежит в корне, а не внутри другой папки.

## Шаг 4. Запустите на Render

1. Откройте **render.com** и зарегистрируйтесь **через GitHub**, так будет проще всего.
2. Нажмите **New** → **Blueprint**.
3. Разрешите доступ к репозиторию `chem-tutor-bot` и выберите его.
4. Render прочитает файл `render.yaml` и попросит заполнить настройки:
   - `BOT_TOKEN` — токен из шага 1
   - `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` — значения из шага 2
   - `ADMIN_IDS` — пока поставьте `0`, а на шаге 5 замените
5. Нажмите **Apply** (или **Deploy Blueprint**) и подождите 2–5 минут, пока сборка завершится.
6. Скопируйте адрес сервиса вида `https://chem-tutor-bot-xxxx.onrender.com` и откройте в браузере `…onrender.com/health`. Если видите `"ok":true` и `"storage":"Upstash Redis"`, всё работает.

Адрес приложения Render передаёт боту сам, отдельно указывать его не нужно.

**Если вместо Blueprint создаёте сервис вручную** (New → Web Service): Runtime `Node`, Build Command `npm install`, Start Command `node server.js`, тариф **Free**, и те же переменные во вкладке *Environment*.

## Шаг 5. Назначьте себя репетитором

1. Откройте своего бота в Telegram и отправьте `/myid`. Если бот не ответил сразу, подождите минуту: сервер просыпается.
2. Бот пришлёт ваш числовой ID.
3. В Render откройте сервис → вкладку **Environment** → у `ADMIN_IDS` поставьте этот номер → **Save Changes**. Сервис перезапустится сам.
4. Отправьте боту `/start`, и появится кнопка **«⚙️ Кабинет репетитора»**.

## Шаг 6. Проверьте

1. Откройте кабинет репетитора и у ближайшего дня нажмите «После школы (15–20)» → **«Сохранить»**.
2. С другого аккаунта (или попросите знакомого) откройте бота → **«📅 Записаться на занятие»** → выберите время → нажмите кнопку внизу.
3. Ученику придёт подтверждение, а вам — уведомление о новой записи.

Ссылку на бота `https://t.me/username_бота` можно ставить в профиль ВК/Instagram, в визитку или отправлять ученикам.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| Бот не отвечает на /start | Подождите минуту: сервер просыпается. Проверьте, что в Render нет ошибок во вкладке *Logs*. |
| В логах «Не удалось подключиться к боту» | Неверный `BOT_TOKEN`: скопируйте его заново у @BotFather. |
| `/health` показывает `файл …` вместо Upstash | Не заданы `UPSTASH_REDIS_REST_URL` или `UPSTASH_REDIS_REST_TOKEN`. Без них записи будут стираться. |
| Кабинет пишет «аккаунт не указан как репетитор» | Проверьте `ADMIN_IDS`: там должен быть номер, который прислал `/myid`. |
| Сайт Render или Upstash не открывается | Попробуйте другой браузер или сеть. |

## Как поменять текст и цены

- Мини-приложение: `public/app.html` (имя репетитора, цены, темы)
- Тексты сообщений бота: `bot.js`
- Сайт-лендинг: `public/index.html`

Отредактируйте файл прямо на GitHub (значок карандаша → *Commit changes*), и Render сам обновит бота через пару минут.

## Кабинет из обычного браузера

`https://ваш-адрес.onrender.com/admin.html`. Пароль Render сгенерировал сам: посмотрите его в *Environment* → `ADMIN_PASSWORD`.

## Локальная проверка

`node server.js` → http://localhost:3000/app.html. Без `BOT_TOKEN` бот выключен, а без Upstash данные сохраняются в файл `data.json`.

## Файлы

- `server.js` — сервер, запись, расписание
- `bot.js` — бот: команды, кнопки, уведомления, вебхук, проверка подписи Telegram
- `store.js` — хранение данных (Upstash или файл)
- `render.yaml` — настройки для Render
- `public/app.html` — мини-приложение записи
- `public/admin.html` — кабинет репетитора
- `public/index.html`, `public/style.css` — сайт-лендинг
- `Dockerfile` — для запуска на других хостингах
